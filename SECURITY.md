# Security reports

Do not put credentials, private source code, personal data or exploitable security details in a public issue.

If this repository's Security tab offers **Report a vulnerability**, use that private reporting channel. If it is unavailable, open an issue requesting a private contact method without including sensitive details. No response-time guarantee is currently offered.

For a report, prepare the affected version, a minimal reproduction, the impact and any suggested fix. Send sensitive reproduction details only after a private channel is established.

All in One runs within the host agent's permissions. Its guidance and evidence helpers are not an isolation boundary. REA is an external pinned npm runtime; native analysis providers are configured separately. Consult the relevant upstream project for vulnerabilities originating in an upstream dependency.
